Model assumptions, equations & future integration

Topology: single-phase PSC example with R–C across supply; ideal run capacitor between R and S; start winding from S to C. No start relay, extra capacitor, parallel branch, leakage or capacitor ESR. This topology must match the equipment before interpreting the illustration.

RMS phasors use exp(+jωt). V_AB = V_A − V_B; C = 0; V_RC = U∠0°. Z_w(f) = Rs + j2πfLs; Z_cap = −j/(2πfC). Stationary: I_s (R→S→C) = U / (Z_s + Z_cap). V_SC = I_s Z_s; V_SR = −I_s Z_cap; V_SC − V_SR = U. Reconstruction: x = (U² + A² − B²)/(2U); y = ±√(A² − x²). V_SC = x + jy, A = |V_SC|, B = |V_SR|; V_SR = V_SC − U. I_s = jωC(U − V_SC). Fitted E = V_SC − I_s Z_s. One-point k_pair = measured pair voltage / measured U.

Three voltage magnitudes leave two mirror solutions. The selected ± imaginary branch is an assumption, not a measured phase direction. Fitted E is a lumped residual for omitted electromagnetic effects, not an independently measured internal source. Line current magnitude cannot establish its phase, true watts or power factor.

At 60 Hz conversion, the app always shows a separate 60 Hz equivalent even if operating frequency differs. Stationary circuit, capacitor current and fitted E use the entered operating frequency. Measured Z and phase at the LCR test frequency are compared with Rs/Ls, with a 5% or 3° review flag (software review thresholds, not instrument specifications).

Reference provenance: user-supplied Copeland ZP16KAE-PFV-130 record in “ICM318 Thermostat Selection.” The user corrected the operating labels to S–C 307 V, R–C 208 V, S–R 222 V and confirmed 120 Hz series LCR mode. Data are not manufacturer specifications. Capacitor 30 µF is nominal; 440 VAC is the recorded rating. Pressure and saturation-temperature observations remain as supplied.

Basic circuit reference: OpenStax: RLC Series Circuits with AC (optional online reading; app needs no network).

Future integration seam: pure calculation engine and versioned JSON record are separate from the interface. A future backend can return manufacturer records with source, retrieval date and verification status. No API credentials, network requests, AI lookup or manufacturer validation exist in phase one. New lookup data must remain distinct from field observations and validated models.

Measurement safety: This notebook does not provide live-testing instructions. Electrical measurements require appropriate training and equipment. De-energize, verify isolation and safely discharge capacitors before disconnected tests.
